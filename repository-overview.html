gateway-api

Public ingress gateway for Aziron services: request routing, per-tenant rate limiting, upstream pooling and graceful connection draining. Written in Go, deployed to every edge region, and verified by Pulse on every push.

Repository structure

cmd/gateway/ binary entrypoint, flag wiring internal/ingress/ request routing + middleware chain internal/limits/ token-bucket rate limiter internal/pool/ upstream connection pool + retry budget deploy/ manifests, shutdown + drain config .github/ verification workflow (pulse-runner v3)
